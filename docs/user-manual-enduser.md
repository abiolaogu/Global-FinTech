# User Manual — End User — Global FinTech Platform (AtlasX)
> Version: 1.0 | Last Updated: 2026-02-18 | Status: Draft
> Classification: Internal | Author: AIDD System

## 1. Getting Started

### 1.1 Creating Your Account
1. Download the AtlasX app (iOS/Android) or visit the web portal
2. Enter your email or phone number
3. Complete identity verification (upload ID + selfie)
4. Set your PIN and security preferences
5. Your account is ready — your default currency wallet is created automatically

### 1.2 Adding Currency Wallets
1. Go to Wallets → Add Currency
2. Select from 50+ available currencies
3. Your new wallet is instantly available

## 2. Sending Money

### 2.1 Peer-to-Peer Transfer
1. Tap Send → Enter recipient (email, phone, or AtlasX ID)
2. Enter amount and select currency
3. Review fees and exchange rate (if cross-currency)
4. Confirm with PIN or biometrics
5. Funds arrive within seconds

### 2.2 International Transfer
1. Tap Send → International
2. Enter recipient bank details (IBAN/account number)
3. View real-time FX rate and total cost
4. Confirm transfer
5. Track status in transaction history

## 3. Managing Your Cards

### 3.1 Virtual Card
1. Go to Cards → Create Virtual Card
2. Select funding wallet
3. Card details available instantly for online purchases

### 3.2 Physical Card
1. Go to Cards → Order Physical Card
2. Enter delivery address
3. Card arrives within 5-10 business days
4. Activate via app by scanning the card

## 4. Cryptocurrency

### 4.1 Buying Crypto
1. Go to Crypto → Buy
2. Select asset (BTC, ETH, USDT, etc.)
3. Enter amount in your local currency
4. View real-time price and fees
5. Confirm purchase

## 5. Security

- Enable biometric authentication (Face ID / Fingerprint)
- Set transaction limits
- Freeze your card instantly from the app
- Enable login notifications
