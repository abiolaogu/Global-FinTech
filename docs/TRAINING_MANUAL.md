### Topics Covered

#### 2.1 Creating Wallets

**Step-by-Step:**
1. Navigate to "Wallets" menu
2. Click "Create New Wallet"
3. Select currency from dropdown
4. Wallet created automatically
5. View wallet details

**Supported Currencies:**
- USD (US Dollar)
- EUR (Euro)
- GBP (British Pound)
- NGN (Nigerian Naira)
- KES (Kenyan Shilling)
- GHS (Ghanaian Cedi)
- ZAR (South African Rand)
- JPY (Japanese Yen)
- CNY (Chinese Yuan)
- INR (Indian Rupee)

#### 2.2 Funding Methods

**Method 1: Bank Transfer**
- Slowest but no fees
- 1-24 hour processing
- Copy provided account details
- Transfer from your bank

**Method 2: Card Payment**
- Instant credit
- 2.9% + $0.30 fee
- Visa, Mastercard accepted
- 3D Secure required

**Method 3: Virtual Account**
- Get dedicated account number
- No fees
- Instant credit
- Use for recurring deposits

**Method 4: Receive from Others**
- Share wallet ID or QR code
- Free
- Instant

## Module 3: Airtime & Data Purchase (60 minutes)

### Learning Objectives
- Navigate airtime marketplace
- Purchase airtime for self and others

### Topics Covered

#### 3.1 Airtime Purchase Process

**Buying Airtime:**

1. **Access Feature**
   - Click "Buy Airtime" button
   - Or navigate to Marketplace → Airtime

2. **Select Destination**
   - Country dropdown (150+ countries)
   - Network/Operator selection
   - System shows available operators

3. **Enter Details**
   - Recipient phone number
   - Amount (or select preset amount)
   - Country code auto-detected

4. **Review & Confirm**
   - Check all details
   - View total cost
   - See commission (if agent)
   - Enter PIN/password

5. **Processing**
   - Real-time processing
   - Usually <10 seconds
   - Confirmation SMS sent

#### 3.2 Data Bundle Purchase

**Bundle Types:**
- **Standard Bundles**: Regular data (1GB, 5GB, 10GB, etc.)
- **Night Bundles**: Cheaper, night-time only
- **Social Media Bundles**: Facebook, WhatsApp, Instagram
- **Streaming Bundles**: YouTube, Netflix optimized
- **Weekly/Monthly Plans**: Best value

**Purchase Flow:**
1. Click "Buy Data"
2. Select country and operator
3. Browse available bundles
4. Filter by:
   - Price range
   - Data amount
   - Validity period
   - Bundle type
5. Select bundle
6. Enter recipient number
7. Confirm and pay
8. Instant activation

#### 3.3 Beneficiary Management

**Why Use Beneficiaries?**
- One-click top-ups
- Save frequently used numbers
- Reduce errors
- Faster transactions

**Adding Beneficiaries:**
1. Go to "Beneficiaries"
2. Click "Add New"
3. Enter:
   - Nickname (e.g., "Mom - MTN")
   - Phone number
   - Country
   - Network
   - Favorite amount (optional)
4. Save

**Using Beneficiaries:**
- Beneficiaries show on home screen
- Tap to initiate transaction
- Pre-filled details
- Just confirm amount

#### 3.4 Auto-Recharge Setup

**Use Cases:**
- Never run out of airtime
- Scheduled top-ups for family
- Business phone maintenance
- Elderly relatives

**Configuration:**
1. Navigate to "Auto-Recharge"
2. Click "Create New Schedule"
3. Set parameters:
   - Phone number (or select beneficiary)
   - Amount
   - Frequency (daily, weekly, monthly, or date)
   - Start date
   - End date (optional)
   - Low balance trigger (optional)
4. Review settings
5. Activate

End: No end date
```

*Configuration 2: Low Balance Trigger*

```

#### 3.5 Commission Structure (Agents/Merchants)

**Agent Commissions:**

| Transaction Type | Commission Rate | Example Earning |
|-----------------|----------------|----------------|
| Airtime (Local) | 2-3% | $10 sale = $0.20-$0.30 |
| Airtime (International) | 3-5% | $10 sale = $0.30-$0.50 |
| Data Bundles | 3-7% | $20 bundle = $0.60-$1.40 |

**Commission Calculation:**
```

```

### 4.2 Split Payments

**Scenario**: Restaurant bill of $100, split 4 ways

**Steps:**
1. Click "Split Payment"
2. Enter total: $100
3. Add participants (3 others)
4. Choose split method: Equal
5. Review: Each pays $25
6. Confirm
7. System:
   - Debits you: $25
   - Requests from others: $25 each
   - Holds your $25 in escrow
   - Releases when all pay
8. Complete!

## Module 5: Offline Features (SMS/USSD) (30 minutes)

### Learning Objectives

### 5.1 SMS Commands

**Format**: `#GFT#COMMAND#DATA#`

**Available Commands:**

| Command | Format | Example |
|---------|--------|---------|
| Balance | #GFT#BAL# | #GFT#BAL# |
| Send | #GFT#SEND#PHONE#AMOUNT# | #GFT#SEND#08012345678#100# |
| Airtime | #GFT#AIR#PHONE#AMOUNT# | #GFT#AIR#08012345678#500# |
| Data | #GFT#DATA#PHONE#BUNDLE# | #GFT#DATA#08012345678#1GB# |
| Status | #GFT#STATUS# | #GFT#STATUS# |

**Send to**: 12345 (Short code)

**Response Time**: <5 seconds

**Example Flow:**
```
You send: #GFT#BAL#
Reply: Balance: $1,234.56
       Available: $1,150.00
       Credit: $500.00

You send: #GFT#AIR#08012345678#500#
Reply: Success! ₦500 airtime sent
       to 08012345678
       Ref: TXN123456
       Balance: $1,145.00
```

### 5.2 USSD Navigation

## Module 7: Security Best Practices (30 minutes)

### Learning Objectives
- Understand security features
- Recognize threats
- Implement best practices
- Handle security incidents

### 7.1 Platform Security Features

**What We Provide:**
- AES-256 encryption
- 2FA authentication
- PCI-DSS compliance
- Regular security audits
- 24/7 monitoring
- Fraud detection AI

### 7.2 User Responsibilities

**DO:**
✅ Use strong, unique passwords
✅ Enable 2FA
✅ Keep software updated
✅ Verify URLs before logging in
✅ Monitor account activity
✅ Report suspicious activity

**DON'T:**
❌ Share PIN/password
❌ Use public WiFi for transactions
❌ Click suspicious links
❌ Give OTP to anyone
❌ Save passwords in browser
❌ Ignore security alerts

### 7.3 Recognizing Threats

**Phishing Attempts:**
- Emails asking for passwords
- Fake login pages
- Urgent security alerts
- Too-good-to-be-true offers

**Red Flags:**
- Misspelled URLs
- Unsolicited contact
- Requests for sensitive info
- Poor grammar in emails

### 7.4 Incident Response

**If Account Compromised:**
1. Change password immediately
2. Enable 2FA
3. Review transaction history
4. Report to support
5. Monitor for unauthorized activity

**Reporting Security Issues:**
- Email: security@globalfintech.com
- Emergency hotline: 24/7
- In-app report button
