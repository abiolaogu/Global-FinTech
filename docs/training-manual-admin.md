# Training Manual — Administrator — Global FinTech Platform (AtlasX)
> Version: 1.0 | Last Updated: 2026-02-18 | Status: Draft
> Classification: Internal | Author: AIDD System

## Module 1: Platform Overview (2 hours)
- AtlasX architecture and component overview
- Admin portal navigation
- Role-based access and permission model

## Module 2: User & Account Management (3 hours)
- KYC/KYB verification workflows
- Account lifecycle management (create, freeze, suspend, close)
- Tier management and limit configuration

## Module 3: Compliance Operations (4 hours)
- RegAI alert review and triage
- Sanctions screening results interpretation
- SAR/STR filing procedures
- Jurisdictional compliance requirements

## Module 4: Payment Operations (3 hours)
- Payment gateway monitoring and health checks
- Settlement reconciliation
- FX rate management and margin configuration
- Dispute and chargeback handling

## Module 5: System Monitoring (2 hours)
- Grafana dashboard interpretation
- Alert response procedures
- Incident escalation matrix
- Performance baseline understanding

## Module 6: Disaster Recovery (2 hours)
- Failover procedures
- Data backup and restore
- Business continuity planning
- Communication protocols during incidents

## Assessment
- Written exam: 60% passing score
- Practical exercise: Handle simulated compliance investigation
- Certification valid for 12 months
