Core Features

Wallet Management

  • Create unlimited multi-currency wallets (USD, EUR, GBP, NGN, KES, GHS, ZAR, etc.)
  • Real-time balance tracking with TigerBeetle's sub-millisecond queries
  • Credit line allocation with configurable limits and interest rates
  • Wallet top-up via bank transfer, card payment, or virtual account
  • Offline spending limits with automatic sync when online
  • Transaction history with advanced filtering and export

Payment Operations

  • Send money between wallets instantly
  • Split payments with atomic execution (all succeed or all fail)
  • Payment links for requesting money
  • Virtual accounts for receiving payments
  • Payment holds with automatic timeout
  • Recurring payments and subscriptions
  • Bulk payments with CSV upload

Airtime & Data Vending

  • Purchase airtime for any mobile network globally
  • Buy data bundles (daily, weekly, monthly plans)
  • Support for 150+ countries and 500+ operators
  • Real-time delivery (typically under 30 seconds)
  • Multi-provider redundancy (Reloadly, DingConnect, Africa's Talking, DTOne)
  • Commission system for merchants and agents (2-10% rates)
  • Gift airtime/data to others

Offline Capabilities

  • SMS sync with AES-256-GCM encryption (#GFT# protocol)
  • USSD menu for feature phones (*789# style)
  • Offline transaction queue with automatic sync
  • Credit line available offline
  • Conflict resolution for concurrent updates

Admin & Merchant Features

  • User management and KYC verification
  • Transaction monitoring and fraud detection
  • Commission rate configuration
  • Analytics dashboard with real-time metrics
  • Provider management and failover configuration
  • Compliance reporting (AML, transaction limits)

TigerBeetle Integration

TigerBeetle is a purpose-built financial accounting database that delivers unprecedented performance:

  • 1M+ Transactions Per Second: 200x faster than traditional databases
  • Sub-millisecond Latency: P50 at 0.5ms, P99 at 5ms
  • Strict Serializability: No race conditions, no eventual consistency
  • Double-Entry Accounting: Built-in support with 128-bit precision
  • Atomic Multi-Leg Transfers: Native support for split payments
  • Zero Downtime: 3-node cluster with automatic failover

Account Structure

TigerBeetle uses a deterministic account ID scheme:

Account ID (128 bits) = [Ledger Code (32 bits)] + [User ID Hash (96 bits)]

Ledger Codes:
- 1000-1099: User Wallets (per currency)
- 2000-2099: Platform Float Accounts
- 3000-3099: Credit Line Accounts
- 4000-4099: Payment Holds
- 5000-5099: Platform Fee Accounts
- 6000-6099: Gateway Settlement Accounts

Offline Architecture

Multi-channel sync for areas with poor connectivity:

  • Internet Sync: Standard API calls with background queue
  • SMS Sync: Encrypted #GFT# protocol with AES-256-GCM
  • USSD Sync: Interactive menu (*789#) with PIN authentication
  • Local Storage: SQLite on mobile with sync queue
  • Conflict Resolution: Server timestamp wins, with user notification
