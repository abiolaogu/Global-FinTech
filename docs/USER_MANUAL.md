## Getting Started

## Wallet Management

### Creating a Wallet

1. Go to "Wallets" menu
2. Click "Create New Wallet"
3. Select currency (USD, EUR, NGN, etc.)
4. Wallet created instantly!

### Funding Your Wallet

**Method 1: Bank Transfer**
1. Go to "Top Up Wallet"
2. Select amount
3. Choose "Bank Transfer"
4. Copy account details
5. Transfer from your bank
6. Funds credited within minutes

**Method 2: Card Payment**
1. Go to "Top Up Wallet"
2. Enter amount
3. Choose "Debit/Credit Card"
4. Enter card details
5. Complete 3D Secure
6. Instant credit

**Method 3: Virtual Account**
1. Get your dedicated account number
2. Use it for direct transfers anytime
3. Auto-credited to your wallet

**Method 4: Receive from Others**
1. Share your wallet ID or QR code
2. Others send money to you
3. Instant credit

### Withdrawing Money

1. Go to "Withdraw"
2. Select wallet and amount
3. Choose withdrawal method:
   - Bank account
   - Mobile money
   - Cash pickup
4. Confirm details
5. Processed within 24 hours

### Using Credit Line

**Eligibility:**
- Tier 2 or 3 KYC
- Good transaction history
- Credit score check passed

**How to Use:**
1. Apply for credit line (one-time)
2. Wait for approval (24-48 hours)
3. Once approved, credit available
4. Spend from wallet (uses credit if balance low)
5. Repay anytime

**Example:**
```
Wallet Balance: $50
Credit Line: $500
Total Available: $550

Purchase: $100
- Deducts $50 from wallet
- Uses $50 from credit
- Credit Used: $50
- Credit Available: $450
```

Perfect for group bills!

1. Go to "Split Payment"

4. Choose split method:
   - **Equal**: Divide evenly
   - **Percentage**: Set percentages
   - **Custom**: Specific amounts
5. Review split
6. Confirm
7. Deducted and distributed automatically!

**Example:**
```

- You: $25
- John: $25
- Sarah: $25
- Mike: $25
```

## Troubleshooting

### Common Issues

#### Transaction Failed

**Possible Causes:**
1. Insufficient balance
2. Network/operator issue
3. Invalid recipient details
4. Daily limit reached

**Solutions:**
1. Check wallet balance
2. Try again in a few minutes
3. Verify recipient number
4. Contact support if persists

#### Airtime Not Received

**What to Do:**
1. Wait 5 minutes (sometimes delayed)
2. Check transaction status in history
3. Note transaction reference
4. Contact support with reference
5. Refund processed if failed

#### Login Issues

**Forgot Password:**
1. Click "Forgot Password"
2. Enter email
3. Check email for reset link
4. Create new password
5. Login with new password

**Account Locked:**
- After 5 failed attempts
- Wait 30 minutes
- Or reset password
- Contact support if needed

#### App Crashes/Freezes

1. Force close app
2. Clear app cache
3. Update to latest version
4. Reinstall if needed
5. Contact support
